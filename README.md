# Dhamma Translate

Public upload page for translation (PDF) and transcription (audio) of
S.N. Goenka Vipassana-tradition Dhamma materials. Output languages:
English and Persian (more later).

This repo hosts only the static GitHub Pages site. The translation
pipeline, glossary, and language profiles live in a private repository;
processing runs on Google Cloud (Vertex AI) with human review before
anything is sent back.

Site: https://flippydippy.github.io/dhamma-translate/
